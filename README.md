# Inteluck Trucker APP Demo

Interactive single-file HTML prototype with all six recovered PRD annotations embedded. The application functionality is unchanged.

## Open and share

Download `index.html` and open it in a modern browser. No installation or local server is required. The demo works offline.

- **Specs: ON / OFF** shows or hides the annotations.
- **Add / Edit Pins** edits the notes; edits are saved in that browser.
- **Export Spec HTML** downloads a new self-contained HTML with your current notes embedded for sharing.

## Included annotations

1. Shipping Record
2. E-POD
3. site photo
4. charges
5. Doc Validity
6. Help

`annotations.json` preserves the original wording and UI anchors as a separate backup.

This is an interactive prototype using mock data, not a production TMS integration.
